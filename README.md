# SGDiscos Frontend

Frontend da plataforma **SGDiscos**, um sistema de e-commerce voltado para a venda de discos de vinil.

Esta aplicação é responsável pela interface do usuário, permitindo que clientes naveguem pelo catálogo de vinis, criem suas contas e realizem compras diretamente pela plataforma.

## 🚀 Tecnologias

* React
* TypeScript
* TailwindCSS
* Redux

## 📚 Sobre o Projeto

Este repositório contém o **frontend da área do usuário**, onde os clientes podem navegar pelo catálogo de discos disponíveis, visualizar informações sobre os produtos e realizar suas compras.

A aplicação foi desenvolvida utilizando **React com TypeScript**, garantindo maior organização e segurança no desenvolvimento, além de **TailwindCSS** para estilização da interface e **Redux** para gerenciamento de estado da aplicação.

## ⚙️ Funcionalidades

* Cadastro de usuário
* Autenticação de conta
* Navegação pelo catálogo de vinis
* Visualização de produtos
* Adição de itens ao carrinho
* Finalização de compra
* Gerenciamento de estado da aplicação com Redux
